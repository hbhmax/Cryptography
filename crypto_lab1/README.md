# Лабораторная работа №1 по основам криптографии (Java)

Реализованы: перестановка битов (P-блок), сеть Фейстеля, DES, DEAL, режимы шифрования
(ECB, CBC, PCBC, CFB, OFB, CTR, Random Delta) и режимы набивки (Zeros, ANSI X.923, PKCS7, ISO 10126).
Готовые криптографические библиотеки не используются, Maven не нужен.

## Что нужно для запуска

Установленный JDK (не просто JRE). Проверка: открыть терминал (командную строку) и набрать

    javac -version

Если выводится версия (например `javac 17.0.2`), всё готово. Подойдёт любая версия от 11 и выше.

## Как запустить

**Самый простой способ**

- Windows: два раза кликнуть по файлу `run.bat`
- Linux / macOS: в терминале, находясь в папке проекта, выполнить `./run.sh`

Файл сам скомпилирует программу и запустит её.

**Вручную (в терминале, из папки проекта)**

    mkdir out
    javac -encoding UTF-8 -d out src/*.java
    java -cp out Main

(В Windows вместо `src/*.java` можно писать `src\*.java`.)

## Что делает программа

После запуска появляется меню, нужно ввести цифру и нажать Enter:

- `1` - проверка DES на известном примере (ключ `133457799BBCDFF1`, текст `0123456789ABCDEF`, должно получиться `85E813540F0AB405`),
  потом шифрование и дешифрование случайных байтов во всех режимах шифрования и набивки. Рядом с каждым пунктом пишется `OK`, если после дешифрования получилось исходное.
- `2` - то же самое для DEAL (случайные байты, все режимы).
- `3` - шифрование и дешифрование всех файлов из папки `files` алгоритмами DES и DEAL во всех режимах.
  Результаты (`.enc` - зашифрованный, `.dec` - расшифрованный) сохраняются в папку `out_files`, в консоли выводится `OK`, если `.dec` совпал с исходным файлом.
  В папку `files` можно положить свои файлы (текст, картинку, музыку, видео, исходники тестов и т. д.).
- `4` - зашифровать или расшифровать один файл: программа спросит алгоритм, режим, набивку, ключ (любой текст), пути к файлам и действие.
  Вектор инициализации (IV) программа делает из введённого ключа сама, поэтому для расшифровки нужно вводить те же алгоритм, режим, набивку и ключ.
- `0` - выход.

Важно: файлы читаются в память целиком, а DES написан простым (не самым быстрым) способом. Файлы в несколько мегабайт обрабатываются нормально,
но для очень больших файлов (сотни мегабайт) пункт `3` будет работать долго, так как перебирает 14 сочетаний. Для больших файлов лучше пункт `4`.

## Как устроено (коротко)

**Перестановка битов (`Permutation.permute`).** Параметры: массив байтов, правило (массив номеров битов), `lowToHigh` и `startIndex`.
Если `lowToHigh == false`, то бит с индексом 0 - это старший бит первого байта (так устроен DES).
Если `lowToHigh == true`, то бит с индексом 0 - это младший бит первого байта.
`startIndex` равен 0 или 1 и говорит, с какого числа начинается нумерация в правиле (в таблицах DES - с 1).
Длина результата равна длине правила (в битах), поэтому перестановка может и сжимать, и расширять данные (в DES так работают E, PC-1 и PC-2).

**Сеть Фейстеля (`FeistelNetwork`).** Раунд: `L(i+1) = R(i)`, `R(i+1) = L(i) xor F(R(i), RK(i))`.
После последнего раунда половинки меняются местами. Благодаря этому (как в конспекте про инволюции) дешифрование - это тот же самый процесс,
только с раундовыми ключами в обратном порядке. Раундовую функцию и генерацию ключей класс получает в конструкторе.

**DES.** Перед сетью Фейстеля выполняется начальная перестановка IP, после неё - конечная IP^-1 (`DES.java`).
Раундовые ключи: удаляются биты чётности (PC-1, 64 -> 56 бит), ключ делится на C и D, они циклически сдвигаются на 1 бит в раундах 1, 2, 9, 16 и на 2 бита в остальных,
затем PC-2 даёт 48-битный ключ (`DesKeyExpander.java`).
Функция F: расширение E (32 -> 48 бит), xor с раундовым ключом, 8 S-блоков (6 бит -> 4 бита: строка из крайних битов, столбец из средних четырёх),
перестановка P (`DesRoundFunction.java`).

**DEAL.** Блок 128 бит, ключ 16, 24 или 32 байта (6 раундов для ключей 16 и 24 байта, 8 раундов для 32 байт). Раундовая функция F - это шифрование DES,
где ключом DES служит раундовый ключ DEAL (адаптер `DesAdapter`). Раундовые ключи `DealKeyExpander` получает шифрованием частей ключа на DES с фиксированным ключом `0123456789ABCDEF`.

**Режимы шифрования (`CipherContext`).** Формулы такие же, как в конспекте (ПЗ-1):

| Режим | Шифрование | Что выполняется параллельно |
|---|---|---|
| ECB | `C = E(P)` | шифрование и дешифрование |
| CBC | `C = E(P xor C_prev)`, `C_0 = IV` | только дешифрование |
| PCBC | `C = E(P xor C_prev xor P_prev)` | ничего (последовательно) |
| CFB | `C = E(C_prev) xor P` | только дешифрование |
| OFB | `O = E(O_prev)`, `C = P xor O`, `O_0 = IV` | ничего (последовательно) |
| CTR | `C = E(IV + i) xor P` | шифрование и дешифрование |
| Random Delta | `C = E(IV + i * delta) xor P` | шифрование и дешифрование |

Параллельность сделана через `IntStream.range(...).parallel()`: каждый блок обрабатывается независимо и записывается в свою часть результата.
В Random Delta `delta` - это вторая половина IV (как в конспекте: IV делится на IV' и delta). Можно передать своё значение последним аргументом конструктора (`Object... extraParams`), например `500L`.
Режимам OFB, CTR и Random Delta дешифрование не нужно (используется только шифрование блока), поэтому для них шифрование и дешифрование - одна и та же операция.
Вектор инициализации нужен всем режимам, кроме ECB, и должен быть равен размеру блока (8 байт для DES, 16 для DEAL). Если IV не передан (`null`), генерируется случайный, его можно получить через `getIv()`.

**Асинхронность.** Методы `encrypt` и `decrypt` возвращают `CompletableFuture<Void>` и выполняются в отдельном потоке. Чтобы дождаться результата, вызывают `.join()`.

**Режимы набивки (`Padding`).**
- `ZEROS` - добавляются нулевые байты (если длина уже кратна блоку, ничего не добавляется). При дешифровании нули в конце отбрасываются, поэтому если сами данные заканчиваются нулевыми байтами, они тоже будут потеряны (особенность этого режима).
- `ANSI_X923` - нули, а в последнем байте длина набивки.
- `PKCS7` - все байты набивки равны её длине.
- `ISO_10126` - случайные байты, а в последнем байте длина набивки.

## Пример использования в коде

    byte[] key = Util.fromHex("133457799BBCDFF1");
    byte[] iv = Util.fromHex("0001020304050607");
    byte[] data = "Hello".getBytes();

    CipherContext context = new CipherContext(new DES(), key, CipherMode.CBC, PaddingMode.PKCS7, iv);

    Result encrypted = new Result();
    context.encrypt(data, encrypted).join();

    Result decrypted = new Result();
    context.decrypt(encrypted.data, decrypted).join();

    context.encrypt("files/sample.txt", "out_files/sample.enc").join();
    context.decrypt("out_files/sample.enc", "out_files/sample.dec").join();
