Меню:

- `1` - проверка DES на известном примере (ключ `133457799BBCDFF1`, текст `0123456789ABCDEF`, должно получиться `85E813540F0AB405`),
  потом шифрование и дешифрование случайных байтов во всех режимах шифрования и набивки. Рядом с каждым пунктом пишется `OK`, если после дешифрования получилось исходное.
- `2` - то же самое для DEAL (случайные байты, все режимы).
- `3` - шифрование и дешифрование всех файлов из папки `files` алгоритмами DES и DEAL во всех режимах.
  Результаты (`.enc` - зашифрованный, `.dec` - расшифрованный) сохраняются в папку `out_files`, в консоли выводится `OK`, если `.dec` совпал с исходным файлом.
  В папку `files` можно положить свои файлы (текст, картинку, музыку, видео, исходники тестов и т. д.).
- `4` - зашифровать или расшифровать один файл: программа спросит алгоритм, режим, набивку, ключ (любой текст), пути к файлам и действие.
  Вектор инициализации (IV) программа делает из введённого ключа сама, поэтому для расшифровки нужно вводить те же алгоритм, режим, набивку и ключ.
- `0` - выход.
