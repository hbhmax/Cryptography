Меню:

- `1` - проверка DES на известном примере (ключ `133457799BBCDFF1`, текст `0123456789ABCDEF`, должно получиться `85E813540F0AB405`),
  потом шифрование и дешифрование случайных байтов во всех режимах шифрования и набивки. Рядом с каждым пунктом пишется `OK`, если после дешифрования получилось исходное.
- `2` - то же самое для DEAL (случайные байты, все режимы).
- `3` - шифрование и дешифрование всех файлов из папки `files` алгоритмами DES и DEAL во всех режимах.
- `4` - зашифровать или расшифровать один файл. 
- `0` - выход.
